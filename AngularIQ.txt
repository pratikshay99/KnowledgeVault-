# 🔴 1️⃣ What is Angular?
> Angular is a TypeScript-based frontend framework developed used to build single-page applications (SPA).
> It provides features like component-based architecture, routing, dependency injection, and two-way data binding.
============================================================================================================================
# 🔴 2️⃣ What is Component in Angular?
> Component is the basic building block of Angular application.
> It controls a part of the UI using HTML template, TypeScript logic, and CSS styling.
Component is a small reusable part of UI.
Angular applications are built using multiple reusable components.
Example:
	Login page
	Navbar
	Dashboard
	User table
Each UI section is usually a separate component. Angular creates separate component for each.
Component contains 3 things:
1️⃣ HTML: UI design
2️⃣ TypeScript: Logic
3️⃣ CSS: Styling
Example:
	@Component({
	 selector: 'app-user',
	 templateUrl: './user.component.html'
	})
	export class UserComponent { }

🎯 Component = one screen section with: UI, logic, styling packed together.
Why components used?
reusable
cleaner code
modular architecture
easier maintenance

# 🔴 3️⃣ What is Data Binding?
 Data binding is communication between TypeScript and HTML template.

		| Binding | Direction | Purpose             |
		| ------- | --------- | ------------------- |---------------------------------------
* Interpolation		| `{{ }}` | TS → HTML | Show text           |DISPLAY data from TypeScript into HTML
* Property Binding	| `[ ]`   | TS → HTML | Set HTML properties |set HTML element properties dynamically.
* Event Binding	| `( )`   | HTML → TS | Handle user events  |capture user actions/events from UI.
* Two-way Binding |`[(ngModel)]`| synchronizes data between UI and component automatically

========================================================================================================================================================
# 🔴 4️⃣ What is Two-Way Data Binding?
> Two-way data binding synchronizes data between UI and component automatically using `[(ngModel)]`.
	<input [(ngModel)]="name">

# 🔴 5️⃣ Difference between ngOnInit and Constructor

#🔴# Constructor
> Used for object initialization and dependency injection.

#🔴# ngOnInit
> Used for component initialization logic after component creation.

---
🔴 Imagine Angular Creating Component

Suppose Angular wants to create: UserComponent

🔥 Step 1 → Constructor Runs FIRST
	constructor() {
   		console.log("Constructor");
	}

Purpose:👉 basic object creation

At this time:
component just created
HTML not fully ready
data binding not finished

🔴 Developer usage of constructor Mostly used for:
   -dependency injection

Example:
	constructor(private service: UserService){}

Angular gives service object here.

🔥 Step 2 → ngOnInit Runs AFTER
	ngOnInit() {
	   console.log("ngOnInit");
	}

Now:
✅ component ready
✅ bindings ready
✅ safe to call APIs

🔴 Real developer usage of ngOnInit
-API calls
-initial data loading
-initialization logic

Example:
	ngOnInit() {
	   this.loadUsers();
	}
🔥 VERY IMPORTANT DIFFERENCE
Constructor
👉 Angular/TypeScript feature
👉 used for object creation

ngOnInit
👉 Angular lifecycle hook
👉 used after component fully initialized

🔥 Real Developer Rule
# Constructor:
-dependency injection
-simple initialization

# ngOnInit:
-API calls
-business logic
-data loading

🔴 Why not API call in constructor?

Because component may not be fully initialized yet.

Angular recommends:
✅ use ngOnInit

Constructor is used for dependency injection and basic object initialization.
ngOnInit is an Angular lifecycle hook used for component initialization logic like API calls and data loading after component creation.

🔴 4️⃣ Synchronous vs Asynchronous
✅ Synchronous: Tasks execute one-by-one.
Example:
	Task1
	wait
	Task2
Next task waits.

✅ Asynchronous: Task runs in background without blocking app.
Example:
	API call started
	↓
	UI still works
	↓
	Response comes later
🎯 Angular mostly uses:✅ asynchronous programming because API responses take time.
	Without async: UI freezes waiting for response.

# 🔴 1️⃣1️⃣ What is Observable (RxJS) ?
> Observable is used for handling asynchronous operations like API calls using RxJS.
Angular API calls are asynchronous.
Observable handles async data streams.
Example:
	this.http.get("/users")
returns Observable.
Why?
Because backend response comes later.
Observable waits & emits(send) data when available.

👉Suppose frontend calls backend API: this.http.get("/users")

Backend response takes time.
Angular cannot freeze UI waiting.
So Angular says: “Okay, response will come later.”

This future-coming data is handled using: ✅ Observable
========================================================================================================================================================
# 🔴 1️⃣2️⃣ What is subscribe()?
> subscribe() is used to receive data emitted by an Observable.
-Observable won’t execute until subscribed.
Example:
		this.http.get("/users")
		.subscribe(data => {
		   console.log(data);
		});
Without subscribe: ❌ no data received.

# 🔴 1️⃣4️⃣ Difference between Promise and Observable
## Promise
* Returns single value
* executes once
Returns:
👉 only ONE future value
Example:
	Order delivered once

## Observable
* Can return multiple values over time
* Supports operators and cancellation
multiple values possible
Example:
	Live cricket score updates

multiple updates possible.

👉 Angular mainly uses Observables because API/data streams fit better.
🎯Promise = one-time result
🎯Observable = stream of results

# 🔴 1️⃣5️⃣ What is Interceptor? Similar to Spring Filter
> Interceptor is used to intercept HTTP requests/responses globally.

Common uses:
* Add JWT token
* Logging
* Error handling
Suppose every API needs JWT token.

Without interceptor:

API1 → add token
API2 → add token
API3 → add token

same repeated everywhere.
✅ With Interceptor

Interceptor automatically adds token before request goes.

Example flow:
Angular Request
↓
Interceptor adds token
↓
Backend API
🔥 Example
	Authorization: Bearer token
added automatically.

# 🔴 1️⃣7️⃣ What is @Input and @Output?
## @Input   : Parent → Child
> Pass data from parent to child component.
Example
	Parent sends username to child component.

✅ date pipe
