# 🔴 1️⃣ What is JPA?

> JPA (Java Persistence API) is a specification used for Object Relational Mapping in Java.
> It helps map Java objects to database tables and reduces the need to write manual SQL queries.

---

# 🔴 2️⃣ What is Hibernate?

> Hibernate is the most commonly used implementation of JPA.
> It provides the actual functionality behind JPA features like entity mapping and database operations.

---

# 🔴 3️⃣ What is ORM?

> ORM (Object Relational Mapping) is a technique that maps Java classes to database tables.
> For example, a User class can be mapped to a users table automatically.

---

# 🔴 4️⃣ What is @Entity?

> @Entity is used to mark a class as a database entity.
> Spring/Hibernate maps this class to a database table.

Example:

```java id="4mjlwm"
@Entity
class User {
}
```

---

# 🔴 5️⃣ What is @Id?

> @Id is used to define the primary key of the entity.

Example:

```java id="yzwcf5"
@Id
private Long id;
```

---

# 🔴 6️⃣ What is JpaRepository?

> JpaRepository provides built-in database operations like save, findById, delete, and findAll without writing SQL queries manually.

Example:

```java id="c1ob8r"
interface UserRepo extends JpaRepository<User, Long>
```

---

# 🔴 7️⃣ Difference between LAZY and EAGER Fetching

## EAGER

> Related data is loaded immediately along with the main entity.

## LAZY

> Related data is loaded only when required.

👉 In real projects, LAZY loading is preferred for better performance.

---

# 🔴 8️⃣ What is @OneToMany?

> @OneToMany defines one-to-many relationship between entities.

Example:

* One user can have many orders.

---

# 🔴 9️⃣ What is @ManyToOne?

> @ManyToOne defines many-to-one relationship.

Example:

* Many orders belong to one user.

---

# 🔴 🔟 How does DB flow work in Spring Boot?

```id="uwrjlwm"
Controller → Service → Repository → Database
```

### Flow:

* Controller handles request
* Service contains business logic
* Repository interacts with DB using JPA/Hibernate

---

# 🔴 1️⃣1️⃣ Why use JPA/Hibernate?

> JPA and Hibernate reduce boilerplate code, simplify database operations, and provide ORM support for easier development.

---

# 🔴 1️⃣2️⃣ Native Query vs JPQL

## JPQL

> Query written using entity names and fields.

## Native Query

> Actual SQL query written directly.

---

# 🔴 1️⃣3️⃣ What is ddl-auto?

> `spring.jpa.hibernate.ddl-auto` controls database schema behavior.

Common values:

* update
* create
* validate

---

# 🔴 1️⃣4️⃣ What is Hibernate Cache?

> Hibernate cache stores frequently used data in memory to reduce database calls and improve performance.

---

# 🔴 1️⃣5️⃣ Difference between save() and saveAndFlush()

## save()

> Saves entity but may delay DB synchronization.

## saveAndFlush()

> Immediately synchronizes changes with database.
